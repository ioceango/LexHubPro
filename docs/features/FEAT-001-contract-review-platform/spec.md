## 2. 背景与目标

企业与个人在签署合同前缺乏低成本的专业审查手段。本迭代交付「法盾审约 LegalGuard」首期：用户上传 PDF 合同后，由 AI 站在委托方立场输出结构化审查报告，包含风险条款、缺失条款、合规性结论与整体安全评分。

## 3. 范围边界

**做**

- 首页：平台能力介绍、核心功能、使用流程、上传入口。
- 上传与审查：PDF 上传至私有对象存储，选择合同类型与自身立场（甲方/乙方），触发 AI 审查并展示分阶段进度。
- 报告详情：整体风险评分、风险条款（高/中/低 + 修改建议）、缺失条款提示、合规性检查、关键条款、复制/导出报告、下载原件。
- 审查历史：统计概览、报告列表、查看详情、删除记录。
- 登录注册与数据隔离：使用平台认证体系，用户仅可见本人合同与报告。

**不做**

- 合同在线编辑、条款自动改写回写。
- 多人协作、审批流、评论。
- Word/图片格式合同解析（仅支持 PDF）。
- 律师人工复核对接。

## 4. 用户故事

1. 作为访客，我可以在首页了解平台能力，并从上传入口进入登录。
2. 作为已登录用户，我可以上传 PDF 合同并选择合同类型与自身立场。
3. 作为已登录用户，我可以查看结构化审查报告与整体评分。
4. 作为已登录用户，我可以在历史记录中回看、复制、导出过往报告，并删除记录。
5. 作为用户，我只能看到自己的合同与报告。

## 5. 功能需求

| 编号 | 需求 |
|------|------|
| FR-01 | 首页展示平台介绍、核心能力、使用流程与上传入口 |
| FR-02 | 上传仅接受 PDF，限制 15MB 与 80 页以内，超限给出明确提示且不发起 AI 调用 |
| FR-03 | 审查请求需携带合同类型与用户立场，作为 AI 审查视角输入 |
| FR-04 | 审查结果包含整体评分（0-100）、风险条款列表、缺失条款列表、合规检查结论、关键条款 |
| FR-05 | 风险条款需带风险等级（高/中/低）与修改建议 |
| FR-06 | 报告页支持复制全文、导出文本、下载合同原件 |
| FR-07 | 历史页展示统计概览与报告列表，支持进入详情与删除 |
| FR-08 | 合同与报告数据按登录用户隔离 |
| FR-09 | 报告页展示「仅供参考，不构成正式法律意见」免责声明 |

## 6. 非功能需求

- 审查接口内部串联 AI 调用，前端调用超时设置为 600 秒。
- 合同原文存放于私有桶，仅持久化对象键，下载时换取临时链接。
- 审查接口不在数据库事务中执行 AI 调用。
- 页面在移动端与桌面端均可正常阅读与操作。

## 7. 验收标准

- AC-01：未登录访问首页可正常浏览，点击上传入口触发登录流程。
- AC-02：上传合规 PDF 后能看到分阶段进度并最终跳转至报告页。
- AC-03：上传非 PDF 或超过 15MB 文件时提示明确原因，且不产生 AI 调用。
- AC-04：报告页展示评分、风险条款、缺失条款、合规结论四类内容且非空结构。
- AC-05：报告页复制、导出、下载原件三个操作均可用。
- AC-06：历史页列表仅显示当前账号数据，删除后列表同步更新。
- AC-07：报告页可见免责声明文案。
