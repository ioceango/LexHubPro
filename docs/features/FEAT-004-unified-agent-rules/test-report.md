## 7. 遗留风险

1. 指针指向性校验采用固定字符串 `.agent/` 匹配。若某份指针只是提及该路径却未实际列出必读清单，门禁仍会判定通过；此为「可自动判定」与「语义正确性」之间的取舍，语义正确性仍依赖评审。
2. `.agent/` 文件为空、指针文件缺失、指针文件为空三个分支逻辑已实现但未逐项构造实测场景（见 §5）。
3. DeepSeek harness (dsh) 目前无官方入口约定，本迭代按通用根 `AGENTS.md` 兜底。若后续 dsh 公布专有约定，需新增一份指向 `.agent/` 的指针文件并加入门禁的 `TOOL_POINTERS` 清单。
4. `.agent/` 与 `docs/rules/` 存在「强约束提炼」与「细则全文」两层表述，后续修改细则时若只改一侧仍可能语义漂移；已通过 `.agent/README.md` 的同步责任条款与优先级声明约束，但门禁无法自动判定语义一致性。
