# BUG-001 登出返回 500 且 OIDC 登出回跳页缺失

| 追溯说明 | 本文档为编号目录制落地后的追溯补录，内容依据实际修复结果整理 |

## 2. 复现步骤

1. 使用已登录账号进入站点任意页面。
2. 点击导航栏「退出登录」。
3. 观察请求结果与页面跳转。

## 3. 实际表现

- 登出接口返回 500 Internal Server Error，用户停留在原页面，无法完成登出。
- 即使登出接口成功，OIDC 登出后的回跳地址在前端不存在对应路由，会出现 404 空白页。

## 4. 期望表现

- 登出接口始终返回可用的跳转地址，不因运行环境变量缺失而报 500。
- OIDC 登出回跳后落到一个风格与站点一致的提示页，用户可从该页返回首页或重新登录。

## 5. 根因

1. 登出接口直接读取动态配置属性获取前端地址。当该变量缺失，或仍保留未替换的占位符值时，属性访问抛出异常并被转换为 500。
2. 前端缺少 OIDC 登出回跳所需的路由与页面，回跳后无匹配路由。

## 6. 影响范围

- 影响所有已登录用户的登出操作。
- 不影响合同上传与审查主流程。

## 7. 验收标准

- AC-01：在前端地址变量缺失时，登出接口不返回 500，且返回可用跳转地址。
- AC-02：在前端地址变量为未替换占位符时，登出接口回退到请求来源地址，不返回 500。
- AC-03：认证签发方信息缺失或地址拼装异常时，接口仍有兜底返回值。
- AC-04：OIDC 登出回跳路径存在对应页面，展示登出成功提示并可返回首页。
- AC-05：补充回归用例覆盖上述配置降级路径。

## 8. 不做事项

- 不改造整体认证体系，不引入第二套登录实现。
- 不修改平台托管的认证回调文件。
